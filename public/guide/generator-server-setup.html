分步动画生成服务（generator-server）配置说明

这是什么

管理后台"添加模型"时，系统会把 .io 零件文件交给你电脑上的一个本地服务，由它调用 Blender + LDraw 零件库，把模型渲染成带分步拼装动画的 assembly_{模型ID}.glb 并自动上传。这个服务很重（Blender + 全量 LDraw 零件库，数 GB），所以装在你自己的电脑上，而不是云服务器。

一键启动（推荐）

在原来能成功生成动画的那台 Windows 电脑上：

  1. 下载一键启动脚本（setup-generator-autostart.bat）
  2. 双击运行，按提示输入 generator-server 所在目录（例如 E:\DevcoProjects\BlockLab\io2glb\tools\ldraw\generator-server）
  3. 脚本会：在独立窗口启动服务（npm start）→ 轮询检测 5177 端口直到就绪（最长 30 秒）→ 提示 [OK]
  4. 看到 [OK] 服务已启动 即可正常使用。服务窗口需保持开着，关窗口或重启电脑后，需再次运行本脚本启动服务

手动启动（临时用一次）

cd 你的项目目录\tools\ldraw\generator-server
npm start

保持窗口开着，服务就在 5177 端口运行；关窗口即停止。

使用前提

  • 用运行了生成服务的那台电脑打开管理后台
  • 地址用 http:// 开头（例如 http://124.221.190.181/admin.html）。HTTPS 页面会被浏览器拦截对本机 http://127.0.0.1:5177 的请求
  • 先点"检测环境"确认 ✅，再上传模型
生成失败不影响模型本身——模型记录、io/glb/说明书都会正常入库，只是暂时没有分步动画，之后补生成即可。
脚本只负责"启动服务"；Blender、LDraw 零件库需要在这台电脑上已经装好（以前用过 test-upload.html 成功生成过动画，就说明已装好）。
